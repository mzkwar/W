# FTTH Multi-Agent Dashboard System

نظام إدارة توزيع مشتركين لوكلاء FTTH العراق متصل مباشرة بـ https://admin.ftth.iq.

## المميزات
1. السحب والمصادقة المباشرة عبر API الموقع الأساسي.
2. لوحة مدير لإضافة الوكلاء الثانويين وتخصيص المشتركين.
3. لوحة مستقلة للوكيل الثانوي لعرض مشتركيه فقط.

## التشغيل المحلي
```bash
npm install
npm start
```
قم بزيارة `http://localhost:3000` للوحة المدير، أو `http://localhost:3000/subagent.html` للوكيل الثانوي.
